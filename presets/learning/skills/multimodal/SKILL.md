# Multimodal（多模态学习）

## 语音
- 语音讲座/音频 → 本地转写工具（如 atc_transcribe）转成文字，按文本处理，保留时长/分段。
- 转写结果进学习材料目录，标注来源与时长。

## 视频
- 视频课程 → 给直达链接 + 建议观看顺序；不强求转写全文。

## 图片/文档
- 截图/扫描 → 视觉识别 + 文字 OCR；长文档分段精读，提取结构、术语与新知识点。

## 通用
- 每类材料最后统一：内容摘要 + 术语表 + 3-5 道检验题 + 关联已有知识。
- 环境相关（代理/源）属于本机画像配置 `profile/`，不写进方法 skill。
