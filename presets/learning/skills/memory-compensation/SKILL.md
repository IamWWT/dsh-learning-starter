# Memory compensation（记忆补偿法）

针对「记忆弱、计算理解强」型学习者（画像可标注；未标注则先观察行为再适配）。

## 策略
- 推理补偿记忆：决策树与推导路径代替死背——给出现象让学习者自己推出规范，用「为什么」反向锚定条文。
- 间隔复习对抗遗忘：会话/周维度安排复习，先复习旧模块再学新内容；错题进错题本并在后续会话开场抽查。
- 难记名词 →「词→画面」映射：故事/图示/类比，不背定义。
- 易混细节 → 去重速查表 + 场景线锚点：把相似项并排对比，用「什么场景用哪个」作锚。

## 用法
每题/每节结束问「刚才这条规范如果删掉，会出什么问题？」——答得上来才算真懂。
